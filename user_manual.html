Standard Operation คู่มือผู้ใช้งาน (User Manual)

ระบบสร้างและจัดการแผนภูมิ Man-Machine Chart

โปรแกรมสร้างแผนภูมิวิเคราะห์ความสัมพันธ์ระหว่างพนักงานและเครื่องจักรระดับพรีเมียม ออกแบบมาเพื่อเพิ่มประสิทธิภาพสายการผลิตแม่พิมพ์เป่า (Blow Molding), แม่พิมพ์ฉีด (Injection Molding) และงานประกอบ (Assembly)

📊 เปิดแอปพลิเคชันใช้งาน ➔

สารบัญคู่มือ

1. แนะนำแผนภูมิ Man-Machine 2. การจัดการไฟล์และโฟลเดอร์ 3. การกรอกข้อมูลขั้นตอนทำงาน 4. สัญลักษณ์และเส้นเวลา (Timeline) 5. การวิเคราะห์สรุปกำลังการผลิต 6. แผนผังพื้นที่ทำงาน (Layout Diagram) 7. การบันทึกและส่งออก PNG / PDF

1️⃣ แนะนำแผนภูมิ Man-Machine Chart

Man-Machine Chart หรือ แผนภูมิการทำงานของคนและเครื่องจักร เป็นเครื่องมือทางวิศวกรรมอุตสาหการ (IE) ที่ใช้สำหรับวิเคราะห์และปรับปรุงประสิทธิภาพการผลิต (Efficiency) โดยจะทำหน้าที่แสดงความสัมพันธ์ด้านเวลาระหว่างกิจกรรมของพนักงาน (Man) และเครื่องจักร (Machine) อย่างเป็นระบบบนแกนเวลาเดียวกัน

💡 วัตถุประสงค์หลัก: เพื่อระบุความสูญเปล่าจากการรอคอย (Idle Time), ปรับสมดุลงาน (Line Balancing) ของพนักงานหลายคน, และลดรอบเวลาการผลิต (Cycle Time) ให้เหลือน้อยที่สุด

โดยเฉพาะอย่างยิ่งในกระบวนการ Blow Molding (แม่พิมพ์เป่า) และ Injection Molding (แม่พิมพ์ฉีด) ซึ่งเครื่องจักรรันรอบอัตโนมัติเป็นเวลานาน แผนภูมินี้จะช่วยให้วิศวกรออกแบบขั้นตอนการทำงานขนานกันได้อย่างมีประสิทธิภาพสูงสุด

2️⃣ การจัดการไฟล์และโฟลเดอร์โครงการ (Sidebar)

ระบบมาพร้อมกับ Sidebar จัดการไฟล์ฝั่งซ้ายมือ ช่วยให้สามารถแยกบันทึกข้อมูลได้ตาม ประเภทกระบวนการ (Process) และ รหัสสินค้า (Product/Part Number):

📁 การเพิ่มโฟลเดอร์กระบวนการ

คลิกปุ่ม "+ New Folder" ด้านล่าง ตั้งชื่อโฟลเดอร์ และเลือกไอคอนกระบวนการ:

  • 💨 Blow Molding (สีน้ำเงิน)
  • 💉 Injection Molding (สีม่วง)
  • 🔧 Assembly (สีเขียว)
  • ⚙️ Custom (สีเทา)

📄 การจัดการไฟล์ชาร์ตในโฟลเดอร์

เมื่อนำเมาส์ไปชี้ (Hover) ที่โฟลเดอร์หรือชื่อไฟล์ จะพบปุ่มคำสั่งควบคุมพิเศษ:

  • ➕ ปุ่มเครื่องหมายบวก (+): สร้างไฟล์ใหม่ภายใต้โฟลเดอร์นั้น
  • ✏️ ปุ่มดินสอ: เปลี่ยนชื่อ (Rename) โฟลเดอร์หรือไฟล์
  • ✕ ปุ่มกากบาท: ลบไฟล์หรือโฟลเดอร์ออกจากฐานข้อมูล

3️⃣ การกรอกข้อมูลขั้นตอนทำงาน (Data Entry)

หน้าจอการกรอกข้อมูลแบ่งออกเป็น 2 ส่วนหลัก:

1. ส่วนหัวเอกสาร (Header Form)

กรอกรายละเอียดเพื่อใช้ระบุหัวเอกสารมาตรฐานการทำงาน ได้แก่ Process Name, Part Number, Model, Cycle Time, Issue Date, Rev. No., Prepared By, Approved By ข้อมูลเหล่านี้จะอัปเดตไปแสดงผลในแถบแสดงผลด้านบนและในเอกสารส่งออกโดยอัตโนมัติ

2. ตารางสร้างขั้นตอน (Step Table Builder)

คลิก "+ Add Step" เพื่อเพิ่มขั้นตอนทำงานใหม่ทีละแถว:

หัวข้อการตั้งค่า รายละเอียดและการกรอก
Process Description พิมพ์คำอธิบายรายละเอียดงาน (เช่น "เปิดประตูปิดงาน", "ประกอบชิ้นส่วน LH")
Operator / Machine เลือกผู้ปฏิบัติงานจาก Dropdown โดยรองรับพนักงาน **Worker A ถึง Worker J** (รวมสูงสุด 10 คน) หรือเลือก **Auto M/C** สำหรับรอบทำงานอัตโนมัติของเครื่องจักร
เวลา (วินาที) กรอกเวลาเป็นตัวเลขวินาทีตามสัญลักษณ์ประเภทงาน:
  • Manual: เวลาที่คนยืนหยิบจับหรือปรับแต่งหน้าเครื่อง
  • Machine: เวลาที่เครื่องทำงานอัตโนมัติ (กรณีระบุ Operator เป็น Auto M/C)
  • Walk: เวลาในการเดินระหว่างสถานี
  • Idle: เวลาที่คนหรือเครื่องว่างงาน (ส่วนตารางจะประเมินผลอัตโนมัติ)
การจัดเรียง (Move) ใช้ปุ่มลูกศร ▲ / ▼ เพื่อสลับตำแหน่งขั้นตอนให้สอดคล้องกับลำดับจริง (Sequence)

4️⃣ สัญลักษณ์สากลและเส้นเวลา (Timeline Symbols)

ระบบจะนำเวลาแต่ละประเภทในตารางมาวาดเป็นแถบสัญลักษณ์อุตสาหกรรมใน **Timeline Visualization** ทันที ซึ่งแสดงผลด้วยลายเส้นเฉพาะตัวดังนี้:

Manual Time

เส้นทึบหนาสีดำ แสดงงานที่ทำด้วยมือพนักงาน

Auto M/C Time

เส้นบางสีน้ำเงินมีหัวปิดหัวท้าย แสดงเครื่องจักรทำงาน

Walk Time

เส้นหยักคลื่นสีเขียว (Zigzag) แสดงการเดินทำงาน

Idle
Idle Time

กล่องกรอบเส้นประสีแดง แสดงพนักงานว่างงาน

💡 **Cycle Time Indicator:** ด้านล่างของแผนภูมิจะแสดงลูกศรสองหัวสีแดงที่ลากขยายขนาดยาวตามเวลาจริง พร้อมระบุเวลา **Total Cycle Time** วินาที เพื่อเช็กเปรียบเทียบกับรอบเป้าหมายที่ตั้งไว้

5️⃣ การวิเคราะห์สรุปกำลังการผลิต (Line Summary)

ในคอลัมน์ด้านล่างขวา ระบบจะรวบรวมเวลาทำงานทั้งหมดของพนักงานแต่ละคนและเครื่องจักรมาแจกแจงวิเคราะห์คำนวณใน **Line Total Summary Table**:

  • Man Time (s): ผลรวมเวลางานแมนนวลของพนักงาน
  • Walk Time (s): ผลรวมเวลาที่พนักงานเดิน
  • Idle Time (s): ผลรวมเวลาที่พนักงานว่างงานหรือรอรอบเครื่องจักร
  • Line Total (s): ผลรวมเวลากิจกรรมทั้งหมดของพนักงานนั้น (Man + Walk)
  • Utilization % (อัตราการใช้ประโยชน์): คำนวณเป็นร้อยละเทียบกับรอบ Cycle Time หลักเพื่อดูความหนาแน่นของงานพนักงานแต่ละคน (แถบสีจะเปลี่ยนตามความพร้อมใช้งาน: สีเขียว ≥ 80%, สีส้ม 50-79%, สีแดง < 50%)

6️⃣ แผนผังพื้นที่ทำงาน (Workstation Layout Diagram)

บอร์ดจำลองผังการวางเครื่องจักรและทิศทางการเดินของพนักงาน ช่วยให้เข้าใจกระบวนการทำงานผ่านภาพจำลองกราฟิก (Workstation layout):

🎮 วิธีการใช้งานผังแบบโต้ตอบ (Interactive Control)

  • เพิ่มอุปกรณ์: คลิกที่แถบสติกเกอร์ด้านบน (Machine, Table, Rack, Worker Pos, Conveyor, Label) เพื่อวางลงบนกริด
  • ย้ายพิกัด: คลิกค้างและลาก (Drag) อุปกรณ์วางในตำแหน่งที่ต้องการ
  • เปลี่ยนชื่อ: ดับเบิลคลิก (Double-click) ที่ตัวอุปกรณ์เพื่อแก้ไขชื่อ หรือพิมพ์ป้ายในกล่องควบคุมแก้ไข
  • ลบอุปกรณ์: คลิกที่อุปกรณ์ที่ต้องการลบ แล้วกดปุ่ม "✕ Delete" สีแดงบนขวา
  • เชื่อมโยงลูกศรเดินงาน: คลิกปุ่ม "↔ Connect" จากนั้นคลิกที่อุปกรณ์ต้นทาง แล้วคลิกอุปกรณ์ปลายทางเพื่อสร้างลูกศร
  • ลบลูกศร: คลิกที่ตัวเส้นลูกศรเพื่อลบการเชื่อมต่อ

7️⃣ การบันทึกและการส่งออกข้อมูล (Save & Export)

💾

บันทึกแผนงาน (Save)

ส่งออกเป็นภาพ (PNG)
