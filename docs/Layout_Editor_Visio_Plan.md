## Job 01 — พฤติกรรมและเกณฑ์รับงาน

- เลือกชิ้นเดียว หรือเลือกหลายชิ้น/กลุ่ม แล้วกด Copy; Paste วางสำเนาและเลือกสำเนาให้ลากย้ายต่อได้ทันที
- Duplicate สร้างสำเนาในครั้งเดียว; ปุ่มและ Ctrl+D ทำงานเหมือนกัน
- เก็บ type, label, shape, สี Shape/Text, font, ขนาด และ rotation; ไม่เปลี่ยนต้นฉบับ
- สำเนากลุ่มมี group ID ใหม่และชื่อ `ชื่อเดิม - Copy` (เพิ่มเลขเมื่อซ้ำ) จึงย้าย/ปรับรูปแบบแยกจากต้นฉบับได้
- Alt-click คัดลอกสมาชิกเดี่ยวออกมาเป็นชิ้นอิสระ; ไม่ติด group ID ของต้นฉบับ
- เส้นระหว่างสมาชิกที่คัดลอก remap ไปยัง ID ใหม่; ไม่พ่วงเส้นไปยังสมาชิกภายนอกชุด
- Paste ซ้ำมี ID ใหม่ทุกครั้งและขยับตำแหน่ง 24 px ต่อครั้ง โดยย้ายทั้งชุดด้วยระยะเดียวกันและรักษาระยะภายในชุด
- Clipboard ของ Layout ใช้ข้ามชาร์ต/โมดูลภายในแท็บแอปเดียวกันได้ และล้างเมื่อ reload; ข้อความในช่องกรอกยังใช้ clipboard ของระบบตามปกติ
- Copy ไม่แก้ข้อมูล; Paste/Duplicate แก้ draft ของชาร์ตที่เปิด ต้องกด Save เช่นเดิม ชาร์ตที่ lock หรือยังโหลดไม่ครบไม่รับ Paste/Duplicate
- ตรวจ automated tests, build/lint, การใช้ปุ่มและ shortcuts ใน browser, บันทึกและ reload บน local D1 ที่แยกจาก Production; ตรวจ Production แบบอ่านอย่างเดียวหลังปล่อย

## รายการทดลองสำหรับเจ้าของ

เผยแพร่ 2026-10-01: [Production editor](https://man-machine-chart.pages.dev/editor), Pages deployment `2520fa0b`, source `44ce754`. ทดสอบ 228/228 ผ่าน, build/lint ผ่าน, local browser Copy/Paste/Ctrl+D และ Save/reload ผ่าน; ปุ่ม Copy บนกลุ่มจริงและข้อมูลเดิมทั้ง 11 โฟลเดอร์ / 19 ชาร์ตตรวจผ่านหลังเผยแพร่แบบอ่านอย่างเดียว ส่วน Ctrl+C/V ทดสอบ handler ผ่าน แต่ browser automation ดักคีย์เข้าคลิปบอร์ดของเครื่องมือ จึงให้เจ้าของลองคีย์สองชุดนี้ด้วยตนเองในรอบทดลอง

1. เลือก Rack → Duplicate → ลากสำเนาออกมาและแก้สี ตรวจว่าต้นฉบับไม่เปลี่ยน
2. เลือกกลุ่ม → Copy → Paste ตรวจชื่อกลุ่มและการย้ายสำเนาทั้งชุด
3. ใช้ Ctrl+C / Ctrl+V / Ctrl+D และลอง Paste ซ้ำ
4. Copy จากชาร์ตหนึ่ง แล้วเปิดอีกชาร์ตในแท็บเดิมและ Paste
5. Save และ refresh ตรวจว่าสำเนายังอยู่ แจ้งจุดที่ใช้งานไม่สะดวกก่อนเริ่ม Job 02

## Job 02 — Undo / Redo

เจ้าของทดลอง Job 01 แล้วและอนุญาตเริ่ม Job 02 เมื่อ 2026-10-01

- ปุ่ม Undo / Redo อยู่ด้านบน Layout; Ctrl/Cmd+Z ย้อนกลับ, Ctrl/Cmd+Y หรือ Ctrl/Cmd+Shift+Z ทำซ้ำ
- ครอบคลุมเพิ่ม/ลบ, ย้าย, ขนาด, หมุน, ชื่อ/สี Shape/Text/Font, Group/Ungroup, Copy/Paste/Duplicate และเส้นเชื่อม/ลูกศร
- ลากหนึ่งครั้งรวมเป็นหนึ่งรายการ; แก้ช่องตั้งค่าระหว่าง focus หนึ่งครั้งรวมเป็นหนึ่งรายการ ปุ่มเลือกสี/รูปแบบแต่ละครั้งเป็นรายการแยก
- ลบรูปทรงแล้ว Undo คืนเส้นที่เชื่อมอยู่ด้วย; Redo ของสำเนาใช้ ID เดิมของสำเนานั้น
- ประวัติเฉพาะ Layout แยกตามชาร์ต เก็บสูงสุด 100 รายการต่อชาร์ตในแท็บปัจจุบัน สลับโมดูล/ชาร์ตและ Save ยังใช้ประวัติได้
- ไม่ย้อนหลังข้อมูล Header/Steps/เวลา/Kaizen; ไม่ย้อนหลังการลบ Chart/Folder ใน Sidebar
- เมื่อ Undo แล้วแก้ Layout ใหม่ จะยกเลิกรายการ Redo; เลือกวัตถุหรือ Copy อย่างเดียวไม่เพิ่มประวัติ
- Refresh/ปิดแท็บ, โหลดข้อมูลใหม่จาก Cloud หรือปิด/เปิด Revision จะล้างประวัติที่เกี่ยวข้อง; ชาร์ต locked/โหลดไม่ครบไม่รับการแก้หรือ Undo/Redo
- Ctrl+Z ขณะ cursor อยู่ในช่องกรอกยังเป็นการย้อนข้อความตามปกติ ใช้ปุ่ม Undo หรือคลิกออกจากช่องก่อนย้อน Layout
- Undo/Redo เปลี่ยน draft; ต้องกด Save เพื่อบันทึกผลเช่นเดิม ประวัติไม่ส่งไป Cloud/localStorage

### รายการทดลอง Job 02

1. ลากกลุ่ม → Undo ครั้งเดียว → Redo ตรวจตำแหน่งทุกชิ้น
2. Duplicate กลุ่ม → Ctrl+Z → Ctrl+Y / Ctrl+Shift+Z
3. เปลี่ยนชื่อและสี → Undo/Redo ตรวจต้นฉบับและสำเนา
4. ลบรูปทรงที่มีเส้นเชื่อม → Undo ตรวจคืนทั้งรูปทรงและเส้น
5. Save → สลับชาร์ตแล้วกลับ → Undo/Redo → Save ผลที่ต้องการ → Refresh ตรวจข้อมูลอยู่ครบและประวัติเริ่มใหม่

ทดสอบ 238/238, build และ targeted lint ผ่าน; local Pages Dev ตรวจปุ่มและ Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z, ลากกลุ่ม, ลบ/คืน, แก้ชื่อ, สลับชาร์ต, Save/API readback และ reload ผ่าน ไม่มี browser console error. ยังไม่เริ่ม Job 03
