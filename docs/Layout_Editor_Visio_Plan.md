# แผนเพิ่มเครื่องมือ Layout โดยอ้างอิง Microsoft Visio

วันที่: 2026-10-01

## วิธีส่งมอบ

ทำทีละ Job → ทดสอบ → เผยแพร่ให้เจ้าของทดลอง → รับข้อเสนอแนะและปรับ Job นั้น → เจ้าของเลือกเริ่ม Job ถัดไป ไม่เริ่มฟังก์ชันถัดไปโดยอัตโนมัติ

แผนนี้เลือกเครื่องมือที่ช่วยจัด workstation / Man Map สำหรับ Injection และ Blow Molding ลำดับหลัง Job 01 เป็นข้อเสนอและปรับได้ตามผลใช้งานจริง

| Job | ฟังก์ชัน | ประโยชน์ / ขอบเขต | สถานะ |
|---|---|---|---|
| 01 | Copy / Paste / Duplicate | ทำสำเนาชิ้นเดียว หลายชิ้น หรือกลุ่ม พร้อมรูปแบบและเส้นเชื่อมภายในชุด; Ctrl+C / Ctrl+V / Ctrl+D | ทดสอบผ่าน — รอเผยแพร่ให้เจ้าของทดลอง |
| 02 | Undo / Redo | ย้อนกลับ/ทำซ้ำการเพิ่ม ลบ ย้าย จัดกลุ่ม และปรับรูปแบบใน Layout; รวมการลากหนึ่งครั้งเป็นหนึ่งรายการ | เสนอ — รอผลทดลอง Job 01 |
| 03 | Align / Distribute | จัดซ้าย กลาง ขวา บน กลาง ล่าง และเว้นระยะเท่ากัน; กลุ่มขยับเป็นชุด | เสนอ |
| 04 | Bring Forward / Send Backward | จัดการวัตถุทับซ้อน เช่น Robot บน Machine โดยรักษาความสัมพันธ์ของกลุ่ม | เสนอ |
| 05 | Grid / Snap / Nudge | เปิดปิดกริดและการจับกริด; ขยับด้วยลูกศรและกำหนดระยะขยับ | เสนอ |
| 06 | Zoom / Pan / Fit | ซูม เลื่อน และแสดง Layout ทั้งหมด โดยตำแหน่งข้อมูลไม่เปลี่ยนตามการซูม | เสนอ |
| 07 | Connector tools | ปรับจุดเชื่อม เส้นหักมุม ป้ายกำกับ และคัดลอกลูกศรเดี่ยวได้สะดวกขึ้น | เสนอ |
| 08 | Format Painter / Change Shape | คัดลอกรูปแบบอย่างเดียว และเปลี่ยนรูปทรงโดยรักษาข้อความ/ตำแหน่ง | เสนอ |
| 09 | Reusable workstation templates | เก็บชุดเครื่องจักร/โต๊ะ/คนที่ตั้งค่าแล้วเพื่อนำกลับมาใช้; ต้องตกลงที่เก็บและสิทธิก่อน | เสนอ |

## Job 01 — พฤติกรรมและเกณฑ์รับงาน

- เลือกชิ้นเดียว หรือเลือกหลายชิ้น/กลุ่ม แล้วกด Copy; Paste วางสำเนาและเลือกสำเนาให้ลากย้ายต่อได้ทันที
- Duplicate สร้างสำเนาในครั้งเดียว; ปุ่มและ Ctrl+D ทำงานเหมือนกัน
- เก็บ type, label, shape, สี Shape/Text, font, ขนาด และ rotation; ไม่เปลี่ยนต้นฉบับ
- สำเนากลุ่มมี group ID ใหม่และชื่อ `ชื่อเดิม - Copy` (เพิ่มเลขเมื่อซ้ำ) จึงย้าย/ปรับรูปแบบแยกจากต้นฉบับได้
- Alt-click คัดลอกสมาชิกเดี่ยวออกมาเป็นชิ้นอิสระ; ไม่ติด group ID ของต้นฉบับ
- เส้นระหว่างสมาชิกที่คัดลอก remap ไปยัง ID ใหม่; ไม่พ่วงเส้นไปยังสมาชิกภายนอกชุด
- Paste ซ้ำมี ID ใหม่ทุกครั้งและขยับตำแหน่ง 24 px ต่อครั้ง โดยย้ายทั้งชุดด้วยระยะเดียวกันและรักษาระยะภายในชุด
- Clipboard ของ Layout ใช้ข้ามชาร์ต/โมดูลภายในแท็บแอปเดียวกันได้ และล้างเมื่อ reload; ข้อความในช่องกรอกยังใช้ clipboard ของระบบตามปกติ
- Copy ไม่แก้ข้อมูล; Paste/Duplicate แก้ draft ของชาร์ตที่เปิด ต้องกด Save เช่นเดิม ชาร์ตที่ lock หรือยังโหลดไม่ครบไม่รับ Paste/Duplicate
- ตรวจ automated tests, build/lint, การใช้ปุ่มและ shortcuts ใน browser, บันทึกและ reload บน local D1 ที่แยกจาก Production; ตรวจ Production แบบอ่านอย่างเดียวหลังปล่อย

## รายการทดลองสำหรับเจ้าของ

1. เลือก Rack → Duplicate → ลากสำเนาออกมาและแก้สี ตรวจว่าต้นฉบับไม่เปลี่ยน
2. เลือกกลุ่ม → Copy → Paste ตรวจชื่อกลุ่มและการย้ายสำเนาทั้งชุด
3. ใช้ Ctrl+C / Ctrl+V / Ctrl+D และลอง Paste ซ้ำ
4. Copy จากชาร์ตหนึ่ง แล้วเปิดอีกชาร์ตในแท็บเดิมและ Paste
5. Save และ refresh ตรวจว่าสำเนายังอยู่ แจ้งจุดที่ใช้งานไม่สะดวกก่อนเริ่ม Job 02
