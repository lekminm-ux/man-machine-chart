// ── ขั้นที่ 1: Count = เวลารวมของแถว (กรอกเท่าไร ได้เท่านั้น ไม่มีการลบ) ── Count(แถวคน) = manual + walk + idle Count(แถวเครื่อง) = machine // ── ขั้นที่ 2: หาว่าแท่งเริ่มตรงไหน ── start(แถวคน) = คนคนนั้นทำแถวก่อนหน้าเสร็จเมื่อไร start(แถวเครื่อง) = งานของคนที่อยู่เหนือมันเสร็จเมื่อไร // คนต้องโหลดก่อนเครื่องถึงทำงานได้ end = start + Count // ถ้ากรอกช่อง Start Time เอง ให้ใช้ค่านั้นแทน (แต่ไม่เอาไปลบ Count) // ── ขั้นที่ 3: Cycle Time คำนวณจากคอลัมน์ Count ── รอบของคน = ผลรวม Count ของคนคนนั้น รอบที่แท้จริง = max( รอบของคน , end ของเครื่องที่คนนั้นเป็นคนโหลด ) Cycle Time = รอบที่ยาวที่สุดในบรรดาคนทั้งหมด

ตรวจกับข้อมูลของพี่: Worker A จะได้ Count 5 + 100 + 220 + 240 + 270 + 361 ซึ่งตัวเลข 4 แถวหลังยังเป็นยอดสะสมเดิมอยู่ — ดูหัวข้อ 4 เรื่องการแปลงข้อมูล

เครื่องเริ่มตอนคนโหลดเสร็จ · คนเดินไปทำงานอื่นขนานกันไป · พอทำงานตัวเองครบก็รอเครื่องจนหยุด แล้ววนกลับ = Cycle Time

3 คอลัมน์ในตารางจะเปลี่ยนไปอย่างไร

คอลัมน์สถานะรายละเอียด
Manual (s)เปลี่ยนความหมายจาก “นาฬิกาเดินถึง” → ระยะเวลาที่คนทำงานในขั้นตอนนี้
Machine (s)เปลี่ยนความหมาย→ ระยะเวลาที่เครื่องทำงานเอง
Walk (s)เปลี่ยนความหมาย→ ระยะเวลาเดิน · รวมกับ Manual ในแถวเดียวกันได้
Idle (s)เปลี่ยนความหมาย→ ระยะเวลารอ
Count (s)เก็บไว้ช่องคำนวณ Cycle Time = เวลารวมของแถวนั้น
แถวคน: manual + walk + idle · แถวเครื่อง: machine
แถวที่กรอกช่องเดียว Count จะเท่ากับตัวเลขที่กรอก · แถวที่กรอกหลายช่อง เช่น ทำงาน 40 + เดิน 8 จะได้ Count 48
Start Time (s)เหมือนเดิมเว้นว่าง = ต่อกันอัตโนมัติ · กรอกเอง = กำหนดจุดเริ่มทับ
สำคัญ: Start Time จะไม่ถูกเอาไป “ลบ” ออกจากเวลาที่กรอกอีกต่อไป มันแค่บอกว่าแท่งเริ่มวาดตรงไหน
Start → Endคอลัมน์ใหม่บอกว่าขั้นตอนนี้อยู่ช่วงไหนบนไทม์ไลน์ เช่น 5 → 105 (เพิ่มเข้ามา ไม่ได้แทนที่ Count)

แสดงตัวเลขบนกราฟ (ตามที่ขอ)

  • เขียน ระยะเวลา กำกับกลางแท่งทุกแท่ง
  • เขียน เวลาเริ่ม–จบ ที่หัวและท้ายแท่ง เมื่อแท่งกว้างพอ
  • แท่งของเครื่องมีป้าย เริ่มเมื่อ <ชื่อคน> โหลดเสร็จ เพื่อให้เห็นว่าตัวเลขมาจากไหน
  • ช่วงที่คนรอเครื่องแสดงเป็นแถบสีเหลืองพร้อมตัวเลขวินาทีที่รอ

7 ข้อดี–ข้อเสียที่ต้องรู้ก่อนตัดสินใจ

ข้อดี

  • กรอกเท่าไร ได้เท่านั้น — ตรงสัญชาตญาณ
  • แก้แถวเดียวไม่กระทบแถวอื่น (เดิมต้องไล่แก้ยอดสะสมทั้งคอลัมน์)
  • M1 กับ M4 พูดภาษาเดียวกัน สะพานเชื่อมง่ายลงมาก
  • ตรงกับฟอร์ม Excel ที่ใช้จริง (คอลัมน์ คน/เครื่อง/เดิน เป็นระยะเวลา)
  • บั๊กแบบที่เจอ 3 รอบที่ผ่านมาจะไม่เกิดอีก เพราะไม่มีการ “ลบ” ให้พลาด

ข้อเสีย / ความเสี่ยง

  • ข้อมูลเดิมต้องแปลง — ถ้าแปลงซ้ำจะเพี้ยน (กันด้วยธงในไฟล์)
  • ถ้าเคยชินกับการกรอกยอดสะสม ต้องปรับวิธีกรอกใหม่
  • ต้องแก้เทสต์ทั้งชุด 73 ข้อ ใช้เวลาพอสมควร
  • ไฟล์ที่เปิดค้างบนเครื่องอื่นตอนแปลง อาจเขียนทับกันได้ — ควรปิดไฟล์บนเครื่องอื่นก่อน
